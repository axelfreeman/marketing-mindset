# Contributing

Thanks for wanting to improve marketing-mindset. Quick rules so PRs land fast.

## Ways to contribute

1. **New model adapter** — add `SKILL.<model>.md` tuned to a specific model's syntax and context limits
2. **Worked example** — a real demo transcript (`examples/`) showing the skill in action
3. **Fix** — typos, broken links, unclear wording
4. **Idea** — open an issue first for anything structural

## Rules

- Keep the voice: sharp, honest, zero fluff. No corporate-speak.
- Adapters must stay under ~60 lines — they are compressions, not rewrites
- No fabricated claims, stats, or testimonials
- English only

## PR checklist

- [ ] One logical change per PR
- [ ] Markdown renders correctly (checked the Files changed preview)
- [ ] New files follow existing naming (`SKILL.*.md`, `examples/*.md`)
